Project Overview:
This project is an end-to-end retail sales analytics project built using SQL and Power BI. The project analyzes Amazon Fresh sales data to uncover business insights through SQL queries and presents the results in an interactive Power BI dashboard.

Objectives:
Analyze retail sales performance.
Identify top-selling products.
Evaluate customer purchasing behavior.
Monitor store performance.
Build an interactive dashboard for business decision-making.

Tools used:
MySQL
SQL
Power BI

Key Features:
